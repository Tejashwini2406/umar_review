# DIFFERENTIAL PRIVACY IMPLEMENTATION REVIEW

The old `scripts/run_privacy_experiments.py` generated synthetic Gaussian examples and its privacy-utility numbers are withdrawn. That entry point now stops with an explicit explanation instead of producing misleading dataset-shaped output.

The current trainer implements per-example global L2 clipping, Poisson sampling without forced nonempty draws, cryptographically sourced Gaussian noise (including noise-only updates for empty samples), and an integer-order RDP upper-bound accountant. Unnoised training losses are not returned. Focused tests cover global clipping, accounting edge cases, empty samples, and schema validation.

This is an implementation correction, not new benchmark evidence. Run `scripts/run_golden_pipeline.py` on verified corrected Stage 3 data to produce exploratory neural-model utility results. The guarantee does not cover the Random Forest, fitted preprocessing, BCL calibration, or the fused ensemble.
